# 页面项目任务直接派发

## 行为与影响范围

页面 `/api/task-intakes/enqueue` 在标题、目标、项目标识通过既有校验后直接创建 `ready` 任务。开启自动调度时由原有 Controller 领取为 execution/bugfix 运行，不再新建隐藏的 `web_task` 需求或等待定位分析记录。用户目标作为初始验收标准，附件直接保存在任务执行契约中。

执行提示要求 Agent 在修改前读取项目规则及已有改动，定位文件、确定最小修改范围和验证方法。用户范围、排除项与附件仍传入执行提示；存在实质歧义或授权不足时报告阻塞。无项目任务保持既有只读行为；独立需求拆解和已有精确文件任务的契约不变。

项目直接任务由服务端写入 `implementation_contract.target_scope=project`。同一判定用于项目排他锁、禁止批次合并和交付文件范围校验。普通精确任务仍限制到原有文件/符号锁。直接任务仍拒绝绝对路径与目录穿越，并在有 Git baseline 的运行中校验真实改动的漏报、虚报；标准代码审查清单由现有 normalizer 生成，支持拒绝与返工。云端现有工作区代理没有 Git baseline，本次不宣称补齐了云端实际差异验证。

## 验证

风险等级 R2：涉及调度与交付状态契约，无数据库结构迁移、无新增生产依赖。

- `./scripts/test tests.test_service tests.test_local_executor tests.test_server tests.test_accounts`：覆盖直接派发、附件、暂停、项目互斥、批次隔离、路径拒绝、真实 Git 差异校验及代码审查通过/返工。
- 账号 HTTP 集成用真实测试服务器验证浏览器新增任务、Agent 领取 execution 和另一账号隔离。
- 独立审查者读取原始差异与调用链，独立运行直接任务及云端 HTTP 测试；发现的审查清单问题已修复，复审接受。
- `./scripts/test`：474 项中 473 项通过，1 项真实 Codex 沙箱探针按环境条件跳过。全量测试启动后新增的双向批次隔离测试另行运行通过（`tests.test_service.TaskboardServiceTest.test_direct_project_tasks_do_not_join_execution_batches`）。生产云端和真实 Codex 执行尚未验证。

## 发布与恢复

本次仅修改源码，不提交、推送、部署或修改已有生产任务。旧 `web_task` 消费路径保留给真实存量任务；旧定位任务不会自动转换，生产恢复需在确认活动运行已停止后另行处理，避免重复执行。

发布沿用现有授权与部署门禁。回退前暂停调度并确认没有活动运行，保存匹配的代码和数据恢复副本。旧版本不理解 `target_scope=project`；只要仍有可执行、待审查或可重试的直接项目任务，就不能用旧版本恢复调度。优先保留数据并前向修复，不静默降级文件范围或删除任务。worktree 模式继续使用既有集成保护，若新定位文件与用户工作区改动重叠，可能在同步阶段才报告冲突。
