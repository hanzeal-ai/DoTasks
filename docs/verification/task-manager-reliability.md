# 任务管理器可靠性修复

本次定位：DoTasks 管理本地工作与开发任务并在云端追踪；实现、执行权限及审查判断属于本地执行会话。保留已授权的连接和下发入口，不扩展为代码实现服务。

风险 R2。范围包括回调幂等、用量回传、登录隔离、离线账号恢复，以及此前已完成的三栏看板与子 agent 审查协调。授权包含提交和推送 main；生产配置、签名证书、许可证授权方案不在本次自动变更范围。

## 契约与恢复

- 同一审查 run 的相同回调返回既有结果，不再次计数；冲突结果拒绝。写入时复核任务与运行状态。
- 本地执行器的 Token 事件按线程/回合去重，排除恢复线程的历史累计。云端保存已上报用量，不将它解释为账单或硬性费用上限。独立子会话用量是否包含在父会话事件中由提供方决定；未获取到的子会话用量不推算。
- 上传失败保留本机私有 outbox；按云端、账号和团队任务隔离，不阻塞执行观察；后续通知、重连或后台检查重试。未上报/部分上报在看板标明。
- 登录按连接来源和账号分桶，保留较大的来源级防遍历上限。代理配置中的真实 IP 信任需由运维单独审查。
- 离线管理员恢复保留账号 ID 与任务/团队数据；可撤销浏览器会话和旧设备绑定，新设备凭新密码一次绑定。没有添加公共密码重置入口。
- 不需要业务数据库 schema 迁移。回退代码时应先停调度和本地会话；若已执行设备恢复，需先用新版本完成新设备绑定后再回退，不可重新启用已经撤销的旧 Token。

## 运维准备

既有部署备份仅用于部署恢复。若将来承诺托管服务，需先由负责人确定备份目标、保留期、可接受数据损失和恢复时间，再配置异地备份与外部告警。本次不修改生产主机，也不把文档当作已实施证据。

发行签名/公证需要拥有者提供证书与发布身份；项目许可证及商业使用条款需要拥有者确定授权方式。未擅自签发证书、选择开源许可证或修改商业条款。

容量风险与完整的客户支持流程仍需专项工作；本轮没有以临时截断任务列表代替分页设计，也未宣称经过规模压测。
