# DoTasks · 同一品牌的三个方向

参考源：CarryOn 当前根目录 `logo.svg`，黑色交叠丝带 C。以当前实际资源为准，未将历史探索当作已确认规范。

推荐 **01-ribbon-d / 交叠 D**：保留 CarryOn 的 14 单位圆头线条、22 单位交叠遮罩和纯黑用色。外轮廓换为 D，左侧继续使用上下穿插的丝带。

- 02-done-d：在 D 中织入完成勾，任务语义更明确，但细节更多。
- 03-split-d：开口 D 与独立短竖线，小尺寸更简洁，穿插特征较弱。

每个方向含图形、横排、竖排三种布局，各有黑、白、蓝三色，以及黑底白标应用展示版，共 30 个 SVG。黑色为品牌主版，蓝色为兼容现有 DoTasks 色彩的备选；白色版用于深色背景。横排采用与 CarryOn 同类的 Arial/Helvetica Bold 字体规则；文字保持可编辑，跨平台字体会有差异，印刷交付前需转轮廓。

## 使用

- 推荐图形画布至少 24px；16px 可辨外轮廓，但交叠留白弱化。预览底部含实际尺寸比较。
- 横排建议至少 140px 宽；保留图形可见宽度约 20% 的外部留白。
- 不拉伸、不单独改线宽、不加阴影、不改交叠间隙。
- 应用图标圆角只作展示；正式商店素材按平台要求导出。
- SVG 无位图和外部资源，遮罩透明，不依赖白色底板。
- PNG 可使用浏览器或矢量编辑器按需要尺寸导出。

01-ribbon-d 已选定并应用到 Web 登录页、侧栏、favicon 及正式品牌资源；其他方向保留为探索稿。`preview.svg` / `preview.svg.png` 为同品牌并排对照。
